# Intelligence Amplification

A static, text-only web edition of the Intelligence Amplification living booklet.

The site is intentionally simple: a single `index.html` file, anchored sections, no artwork, no build step, and no framework dependency.

## Local preview

Open `index.html` directly in a browser.

## Deployment

This repository deploys to GitHub Pages at https://intelligenceamplification.github.io/.

### Current IAM links

For each new IAM issue, verify that promotional and navigation links on every public page open the current reader at `/intelligence/`. Update numbered labels to match the issue that opens. Retain permanent issue and archive links inside IAM, and identify any historical metrics by issue.
