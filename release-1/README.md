# Release 1 capability explorer

The approved Expression, Languages and Execution experience is mounted into the homepage. The original homepage sections and IAM Reader are preserved.

Run `npm install` and `npm run build` here. The compiled files are written to `../assets/release-1/`; update the homepage stylesheet and module filenames after rebuilding. CSS is scoped to `#capability-explorer` to preserve the surrounding site. No AI API or visitor account is required.

Language X-Ray and the English, Spanish and Vietnamese origin lesson come from Nuevo Flow. Other prepared translations and reading guides retain their draft review labels. Computer workflows are illustrative fixtures, not live or recorded agent runs.
